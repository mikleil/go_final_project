# Планировщик задач. 

## Описание.
Хранение задач, которая каждая из них содержит дату дедлайна и заголовок с комментарием.
Задачи могут повторятся, в зависимости от настроек, ежедневно, ежемесячно, ежегодно, а так же в определённые дни месяца или недели.

При выполнении задачи, она автоматически переноситься на день, который указан в настройках повтора.

В случае обычной задачи, при отсутствии повтора, она удаляется.

## Основные фукции задачника.
- Создание задачи, с установкой повтора задачи
- Редактирование задачи
- Отметка о выполнении
- Удаление задачи
- Поиск задачи по `Названию` или `Комментарию`
- Поиск задачи по дате


## Задачи со звездочкой.
- порт вынесен в переменную окружения TODO_PORT в файл .env
- название базы данных вынесено переменную окружения TODO_DBFILE в файл .env
- Вычесление следующих дат в случае недель и месяцев
- Реализован поиск задач в полях `title` и `comment`, а так же по дате

## Пример .env
   ```.env
   TODO_PORT=7540 \
   TODO_DBFILE=scheduler.db
   ```

## Запуск в браузере.
   http://localhost:7540
